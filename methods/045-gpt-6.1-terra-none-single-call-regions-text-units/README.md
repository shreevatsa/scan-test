# 045-gpt-6.1-terra-none-single-call-regions-text-units: GPT-6.1 Terra without reasoning, one call for regions, per-line text and the unit tree

This is the single-call variant of the pipeline: one request does the work of [method 042](../042-gpt-6.1-terra-none-book-types-continuations/README.md) (regions) and [method 044](../044-gpt-6.1-terra-none-region-transcription/README.md) (text and units). Then [method 043](../043-gpt-6.1-terra-none-book-types-continuations-band-chained-lines/README.md)'s local step runs unchanged on its boxes, and a page document of the draft book schema is built.

## The request

The request is method 042's: the raw PNG to `gpt-6.1-terra` with reasoning effort `none`, image detail `original`, strict JSON Schema, `store=false`. The only setting changed is at most 32,768 output tokens. The prompt (`prompt.py`, `prompt-template.txt`) has three parts:
1. **Regions:** method 042's prompt for the book, generated by `region_prompt.py` (a byte copy of method 042's `prompt.py`): region types with their class rules, larger units, the nesting rule, and the continuation, reading-order and uncertainty rules. Method 042's rule against transcription is dropped, and regions are numbered `r1, r2, …` in the order listed.
2. **Transcription:** method 044's rules (exact transcription, `word[1]` note markers, line ends, the book's conventions). Each region lists its printed lines, with no fixed count, because the line finder has not run yet.
3. **Units:** method 044's rules, with the unit types, furniture, flows and relations generated by `transcription_prompt.py` (a byte copy of method 044's `prompt.py`).

Each region in the response has method 042's fields plus `lines` (text and end) and `note`; then come units, flows and relations as in method 044.

## Local steps

1. The boxes are validated and scaled by `regions.py` (a byte copy of method 042's) and written as a method 042-style `regions.json`.
2. Method 043's `run.py`, unchanged, computes polygons and line pieces into `local/`.
3. **Alignment:** each region's lines are matched to its line pieces.
   - When the counts are equal, by position.
   - When there are more pieces than lines, the smallest pieces get empty text if each has under a quarter of the median piece's ink (a detached vowel sign or repha that the line finder made a line of its own).
   - Otherwise no text goes on the pieces, and the region's lines are kept in its `source`.

   Relation line numbers are mapped the same way.
4. `pagedoc.py` (a byte copy of method 044's) writes `page.json` and `transcript.txt`, and `schema/book.py` checks the document.

`result.json` records the alignment of every region, the local step's diagnostics, problems and the check.

## Run

```sh
cd methods/045-gpt-6.1-terra-none-single-call-regions-text-units
uv run --offline python run.py ../../inputs/hertel-panchatantra-page-152.png --check
uv run --offline python run.py ../../inputs/hertel-panchatantra-page-152.png
```

Scoring uses method 044's `evaluate.py`, `tree.py` and `assemble.py`. Method 043's `evaluate.py` scores the polygons in `local/regions.json` against the passage references.

## Recorded results

Two requests on each of the 12 Kale, Hertel and Dutt run pages. See "Method 045" in [NOTEBOOK.md](../../NOTEBOOK.md). In brief:
- **Cost and time:** $0.348 for the first requests and $0.215 for the repeats, against $0.165 + $0.387 for methods 042 + 044. Median API time 38 s and 41 s for the one call, against about 13 s + 28 s for the two.
- **Regions:** method 043's polygons score 0 / 0 / 0 on the three referenced pages. On Hertel 152 the call returned no regions for two margin line numbers, which went to text regions: 2,462 pixels of ownership errors.
- **Alignment:** line text was put on the line pieces of 233 of 236 regions in each request. The three exceptions are Hertel's running header and tale line, which the line finder joins into one line piece.
- **Text** (kept passages, markers ignored, first request / repeat): Hertel 152 0.44% / 2.18%; Kale 106 2.18% / 2.31%; Dutt page 2 0.34% / 0.67%.
- **Trees:** every example unit matched by type and regions on all seven example pages in both requests. Open ends:
  - all right on Dutt pages 2–3 (method 044 wrongly opened page 2's first group);
  - Kale's commentary at the top of pages 108–109 still marked as begun earlier;
  - Hertel 153's first paragraph marked as begun earlier and its last as going on.
- **Validity:** 11 of 12 page documents in each request; Hertel 153 is invalid in both.

## Limitations

Those of method 044, and:
- the text cannot be checked against line pieces until the local step has run, so a region whose line count disagrees keeps its text only in `source`;
- a margin number the call does not return as a region goes into the neighboring text region;
- the call is longer, so a failure loses both regions and text.
